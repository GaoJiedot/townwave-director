# 场景资产管理引擎（模块④）

> 吸收：`scene-multi-angle-generator`（多角度+索引表+场景圣经）、`bootstrap-locations`（6 维度设定）、`vr-panorama-generator`（360° 全景）。
> 所有产物回写 `bible.md` 的 scenes[]，发放**场景圣经 + 镜头索引表**，供⑤分镜自动引用，杜绝"分镜里又出新场景"。

---

## A. 场景设定 6 维度（先填后出图）

| 维度 | 内容 |
|---|---|
| 类型 | 室内/室外/奇幻空间 |
| 时间 | 年代、时段、季节 |
| 空间 | 尺寸、层高、门窗位置、布局 |
| 光影 | 光源位置/性质（自然/人造/体积光）、明暗对比 |
| 叙事功能 | 该场景承载的情绪/事件 |
| 关键物件 | 固定道具、布景元素（大量重复物带来风格冲击） |

---

## B. 多角度参考图提示词（四宫格/六角度）

```
[风格前缀]
[场景描述：类型+时代+装饰风格+色彩风格]
多角度空间参考图，保证元素位置跨角度严格一致：
- 全景俯视(aerial/top-down)：展示整体布局与空间关系
- 主视角平视(eye-level)：主要活动区域，关键元素位置一致
- 反向角度(reverse)：从场景另一端看回
- 道具特写(close-up)：关键道具材质，consistent with 主视角
[画质词]
```

## C. 场景圣经 + 镜头索引表（必出，下游⑤自动引用）

```markdown
## SCENE-01 场景圣经
- 空间尺寸：4m×5m，层高2.8m，南向窗
- 固定道具：布艺沙发、实木茶几（位置锁定）
- 可变道具：茶具、遥控器
- 光照条件：傍晚自然光+暖色吊灯，丁达尔效应
- 色彩基调：主色暖木 #C8A06A / 辅助冷灰 #6B7280 / 强调暖橙 #E08A3C / 禁用荧光

## 镜头索引表（分镜按类型选参考图，禁止重描场景）
| 镜头类型 | 相机方向 | 参考图ID |
| 建立镜头 | 全景俯视 | SCENE-01_top |
| 主视角对话 | 平视正面 | SCENE-01_front |
| 过肩镜头 | 侧后方 | SCENE-01_ots |
| 道具特写 | 平视近景 | SCENE-01_close |
| 反应镜头 | 反向平视 | SCENE-01_reverse |
```

> **环环相扣关键点**：⑤分镜写"主视角对话"时，直接写 `引用 SCENE-01_front`，不写"一个暖色客厅"。新增自检（机制5）会抓出任何自由场景描写。

## D. 环境色卡 HEX（P3b）

- 从 6 维度推导具体 HEX：主色/辅助色/冷暖关系/局部强调色/肤色保护/禁用色/黑位倾向。
- 色值必须有设定依据，不臆造。作为⑥视频色彩硬锚点。

---

## E. 360° 补角（仅关键场景）

```
[风格前缀]
equirectangular 360 panorama, 5824×2880,
[场景描述]，完整环视空间，元素位置与场景圣经一致，
[光照统一]，[反向提示词：扭曲/接缝/模糊]
```
- 只对需环视连续性场景（长镜头/转身/跨轴）出，避免烧钱。
