# 角色 / 道具提示词引擎（模块③）

> 吸收：`short-drama-character-prompt-agent`（最扎实的角色提示词）、`character-model-sheet`（三视图卡）、`character-consistency-helper`（一致性落地）。
> 本引擎所有产物必须回写 `bible.md` 的 characters[] / props[]，并发放**锁定事实块**供下游⑤⑥只引用不重述。

---

## A. 角色母板（9:16 确认稿）提示词结构

```
[风格前缀 style_prefix]
[时代穿搭体系：古风/现代/仙侠/民国/科幻 — 选一]
[神颜/写实锚点：具体骨相、五官、肤质、发型，拒绝套话]
[SSS 级画质参数：超写实摄影感、中画幅质感、皮肤纹理、毛发细节]
[服装：具体款式+材质+固有色，与时代体系一致]
[身份/职业锚点：决定体态与气质]
[动作/姿态：自然非摆拍]
[负向约束：见下方绝对禁令]
[比例：9:16]
```

### 去撞脸质量层（每角色必带，相邻角色至少改 5 个维度）
- 维度清单：骨相、眼型、鼻型、唇形、发型、体型、肤色、年龄感、标志性配饰。
- 禁同主导脸源；每角色 2-4 个记忆点（如"左眉疤/单眼皮/方颌"）。
- 东亚去同质化；写实≠低曝光；禁蜡像感、禁网红 AI 脸、禁塑料光泽。

### 绝对禁令（写入每条角色提示词）
```
禁止：对称完美脸、网红脸、精修磨皮、塑料光泽、瓷娃娃皮肤、
过度滤镜、重复雷同五官、西方默认骨相（除非设定需要）
```

### 参数速查（可按风格微调）
- 写实影视：`ultra-realistic, medium format photography, 8k, skin pore texture, natural lighting`
- 画质后缀：`masterpiece, best quality, highly detailed`

## D. 一致性落地（character-consistency-helper 精神）

- 下游⑤⑥引用角色时，只传 `CHAR-0X` + 锁定事实块，不重新描写外貌。
- 同一角色多状态（受伤/换装/年龄）必须基于定稿图生成，不得另起炉灶。
- 版本管理：bible 中记录 `CHAR-01(v1)`，修改产生 `v2`，ledger 追溯。
